## 3. 竞品分析

### 竞品列表

| 产品名称 | 核心功能 | 定价模式 | 差异点 | 市场表现 |
|---------|---------|---------|--------|---------|
| **Runway** | 文本/图像生成视频、镜头控制、后期编辑、4K 输出 | 订阅制，多档位（公开评测中常见 Standard/Pro/Unlimited） | 偏“专业创意生成 + 后期控制”，更适合工作室和品牌内容团队 | 在 2026 年多篇 AI 视频工具盘点中被列为头部专业级工具 |
| **Canva** | 拖拽式视频模板、品牌素材、动画、字幕、团队协作 | 免费 + Pro + 团队版 | 偏“模板化内容生产”，上手门槛低，但 AI 合成深度不如原生视频生成平台 | 在营销与非设计人群中渗透率高，常被视为轻量营销视频入口 |
| **CapCut / 剪映** | 移动端与桌面视频编辑、模板、字幕、特效、AI 辅助剪辑 | 免费为主，部分高级能力订阅/内购 | 偏“剪辑与分发效率”，不是以 AI 原生生成链路见长 | 依托短视频生态，适合高频创作者和移动端快速出片 |
| **InVideo** | 脚本转视频、营销视频模板、配音、品牌元素、自动化成片 | 免费 + Business/Unlimited 等订阅层级 | 明显面向营销视频与批量产出，比纯剪辑工具更偏内容流水线 | 在 2026 年工具榜单中被频繁提到，适合中小商家与营销团队 |
| **Pika** | 文本/图像快速生成短视频、创意特效、快速变体 | 免费额度 + 订阅/点数 | 偏“快生成、强创意”，适合爆款片段和实验性内容，不是完整成片工作流 | 以速度和特效出名，常与 Runway、Sora 等并列比较 |
| **Kling / 可灵 AI** | 文/图生视频、较长时长输出、多模态创作、API 能力 | C 端订阅 + 企业 API | 本土化能力强、适合竖屏与商业内容，但更偏生成平台，不是模板化营销流水线 | 2025-2026 中文语境下高频出现的 AI 视频平台，商业集成讨论度高 |

### 市场洞察

- **市场空白**：市场已经存在两类成熟方案——一类是 **AI 原生生成型**（Runway / Pika / Kling），另一类是 **模板化内容生产型**（Canva / CapCut / InVideo / VEED）。真正的空白不在“做短视频”本身，而在于是否能为**非专业用户提供“从脚本/素材到可发布短视频”的低门槛闭环**。
- **差异化机会**：
  1. **提示词工具 → 成片工具闭环**：如果复用现有 VideoPrompt AI 的创意生成能力，再补模板化合成链路，可形成“创意生成 + 快速成片”的差异化路径。
  2. **聚焦营销/电商短视频而非全能编辑器**：相比直接挑战剪映/Canva，全力聚焦商品介绍、活动预热、口播视频、图文转视频，更容易形成明确场景价值。
  3. **降低生成不可控性**：相较纯 AI 文生视频，模板化镜头编排 + 可控素材替换更适合企业和商家高频出片。
- **潜在风险**：
  1. 巨头竞争强，通用视频编辑和 AI 视频生成两端都已有头部产品。
  2. 若同时做“AI 生成 + 模板编辑 + 渲染导出 + 多端适配”，范围会迅速失控。
  3. 商业化会被算力、转码、存储、版权素材和审核成本拉高。

### SWOT 分析

| | 有利 | 不利 |
|---|------|------|
| **内部** | **S 优势**：已有 `VideoPrompt AI` 的创意生成基础和相关用户假设，可向“成片”延伸；短视频创作者/营销用户画像与现有领域相邻 | **W 劣势**：当前基线架构明确“不包含视频生成、图片生成”，与短视频合成所需能力差距较大；仓库尚未体现素材管理、转码、项目管理等能力 |
| **外部** | **O 机会**：AI 视频与图文转视频需求持续增长，小团队、商家和内容工作室正在寻找更低门槛的内容生产工具 | **T 威胁**：Canva/CapCut/InVideo 等对模板化场景覆盖已深，Runway/Kling/Pika 等在 AI 生成端持续迭代，市场教育成本低但竞争强度高 |

## 4. 商业模型快评（Lean Canvas）

| 要素 | 内容 |
|------|------|
| **用户痛点 Top 3** | 1. 做一条短视频往往要跨脚本、配图、字幕、配音、剪辑多个工具，流程碎片化<br>2. 现有工具要么太专业（编辑器重），要么太偏 AI 生成（结果不可控）<br>3. 商家/运营需要高频、稳定、可复用的成片能力，而不是一次性创意实验 |
| **解决方案** | 用模板化短视频工作流承接“脚本/图片/素材 → 镜头结构 → 字幕/配音/BGM → 导出”，必要时再叠加 AI 辅助生成封面、文案、镜头建议 |
| **独特价值主张** | “把创意输入压缩成 10 分钟内可导出的短视频”——比纯剪辑工具更省操作，比纯 AI 生视频更可控 |
| **目标客群** | 早期更适合电商商家、内容运营、营销团队与轻量创作者，而非专业影视团队 |
| **获客渠道** | 电商与新媒体运营社群、短视频培训社群、SEO（图文转视频/营销视频生成/商品视频制作）、现有 AI 创作工具用户迁移 |
| **收入模式** | 建议优先考虑 Freemium + Pro 订阅；对高成本能力（AI 配音、高清导出、批量导出、素材包）采用额度或增值包模式 |
| **关键指标** | 1. 首条视频导出成功率<br>2. 首次成片耗时（Time to First Video）<br>3. 周导出视频数/用户<br>4. 7 日留存率<br>5. 免费→付费转化率 |
| **成本结构** | 开发人力、视频转码/渲染、对象存储/CDN、TTS/音乐/字幕第三方能力、内容审核、版权素材采购或授权 |

## 5. 可落地性快评

### UI 复杂度初评

| 评估项 | 结论 | 说明 |
|--------|------|------|
| **核心用户路径** | 一般 | 主流程可定义为“输入脚本/素材 → 选模板 → 生成草稿 → 调整字幕/配音/BGM → 导出”，但比现有提示词工具多出素材、预览、导出等多个环节 |
| **页面与状态复杂度** | 高 | 至少涉及工作台、模板选择、项目编辑、素材上传、导出页、历史项目、额度/计费页；并有空状态、上传中、生成中、渲染失败、额度不足、权限受限等状态 |
| **交互风险** | 高 | 若引入时间线、多段镜头、字幕逐条编辑、配音试听、横竖屏切换等能力，交互复杂度会迅速提升 |
| **MVP 可收敛性** | 中 | 可以压缩为“脚本/图文 → 模板化营销视频 → 一键导出”的 MVP；不建议首版就做完整时间线编辑器或强 AI 文生视频 |

**UI 复杂度结论**：高

### 技术可行性初评

| 评估项 | 结论 | 说明 |
|--------|------|------|
| **技术可行性** | 中 | 如果定位为模板化合成与轻量 AI 辅助，技术上可行；如果定位为高质量 AI 原生视频生成 + 可编辑工作流，复杂度显著上升 |
| **实现复杂度** | 高 | 需要新增模板引擎、字幕/配音/BGM、渲染转码、项目存储、导出链路；与现有“提示词格式化 + AI 扩写”不是同一量级 |
| **关键依赖** | 多 | 依赖视频处理链路、对象存储、TTS、音乐/素材版权、字幕能力，若叠加 AI 生成还会依赖外部模型/API |
| **系统风险** | 高 | 主要风险在性能成本、渲染失败率、版权合规、内容审核和导出稳定性 |

**技术快评结论**：建议缩范围推进

## 7. 结论与建议

**结论**：⚠️ 建议缩范围推进

**理由**：
短视频合成赛道有真实需求，但并不缺工具，直接做“全能型短视频合成 app”会同时落入强竞争和高复杂度区间。对当前仓库上下文而言，更合理的路径是把现有 `VideoPrompt AI` 从“创意前置工具”延伸为“模板化成片工具”，先验证营销/电商/图文转视频这类高频且可控的 MVP 场景。

**建议版本变更类型**（仅迭代模式）：Major
**版本变更依据**（仅迭代模式）：从“提示词工具”扩展到“成片生产工具”，属于核心产品边界和能力模型的重大变化，涉及功能域、交互模型和技术边界的整体升级。

**下一步行动**：
1. 先补一轮需求澄清：确认目标场景是“营销视频 / 图文转视频 / 口播视频 / AI 原生生成视频”中的哪一类，并收集至少 5 位目标用户访谈。
2. 将 MVP 收敛为“脚本/图文 → 模板化短视频 → 一键导出”，暂不做完整时间线编辑器和高成本 AI 原生视频生成。
3. 若继续推进，下一步应由 `requirement-doc` Skill 基于本报告输出正式迭代 PRD，并在 PRD 评审后再由 Architect Agent 补正式架构迭代方案。
