## 1. 背景与目标

### 1.1 项目背景

VideoPrompt AI 在 v1.0-v2.0 阶段聚焦于「AI 视频/图像提示词生成」，核心价值是帮助用户更快完成创意表达和多模型适配。随着需求延伸，用户真正想要的并不只是“写出好提示词”，而是**把脚本、图片、商品素材快速变成一条可发布的短视频**。

结合附录 A 中的立项分析，本次 v3.0.0 需求迭代将产品方向从“提示词工具”升级为“**模板化短视频合成工作台**”：

1. 面向电商商家、内容运营、营销团队和轻量创作者，提供从脚本/图文输入到导出成片的闭环；
2. 避免首版直接进入高成本、高不确定性的纯 AI 文生视频路线，而是优先采用**模板化镜头编排 + AI 辅助文案/字幕/配音**的 MVP 路线；
3. 复用既有 VideoPrompt AI 的创意输入和 AI 辅助能力，向后延伸到素材组织、字幕、配音、BGM、导出与项目管理；
4. 将产品定位收敛在“10 分钟内做出可发布营销短视频”的效率工具，而不是完整的视频编辑器。

> **命名说明**：本次 v3.0.0 迭代对外产品名称暂定为 **VideoPrompt AI Studio**，用于区别于历史阶段的“提示词生成器”定位。

> 📝 立项验证详情见附录 A，其中 A.3 对“短视频合成 app”方向进行了专门分析，并建议采用“脚本/图文 → 模板化短视频 → 一键导出”的 MVP 路线。

### 1.2 业务目标

1. **验证模板化短视频合成场景是否成立**：在首个版本中覆盖图文转视频、商品介绍视频、活动预热视频 3 类典型场景。
2. **将首条视频导出时间压缩到 10 分钟内**：让非专业用户在单次会话中完成输入、模板选择、内容调整与导出。
3. **建立从创意到成片的闭环能力**：补齐脚本输入、分镜草稿、字幕、配音、BGM、导出、项目复用链路。
4. **为后续商业化建立可计费能力**：以高清导出、AI 配音、品牌模板包、批量导出等能力作为 Freemium 向 Pro 升级基础。

### 1.3 成功指标

| 指标 | 目标值 | 衡量方式 |
|------|--------|----------|
| 首条视频导出成功率 | ≥ 85% | 导出日志统计 |
| 首次成片耗时（TTFV） | ≤ 10 分钟 | 前端埋点 + 导出时间戳 |
| 周导出视频数/活跃用户 | ≥ 2 | 项目导出记录 |
| 7 日留存率 | ≥ 25% | 用户行为分析 |
| 模板使用率 | ≥ 60% | 模板加载埋点 |
| 免费→付费转化率 | ≥ 2%（上线 3 个月） | 支付系统统计 |

|------|------|----------|----------|
| 电商商家 / 店铺运营 | 25-40 岁，擅长文案和商品卖点梳理，但不会专业剪辑 | 快速把商品图、卖点文案、促销信息合成为 9:16 宣传视频 | 新品上架、活动促销、平台直播预热 |

### 4.2 功能详细描述

#### 4.2.1 脚本/图文输入与创作向导

- **所属模块**：创作输入
- **描述**：用户在首页输入商品卖点、活动文案、课程介绍或上传图文素材，系统引导进入短视频生成流程。
- **输入**：文本脚本、图片素材、模板场景选择
- **处理逻辑**：提取关键信息（主题、卖点、目标场景、时长偏好），生成创作上下文并进入模板选择/分镜草稿生成
- **输出**：创作任务草稿、推荐模板、默认视频比例
- **异常场景**：文本过短、图片格式不支持、主题信息不完整时提示补充

#### 4.2.2 模板选择与一键套用

- **所属模块**：模板引擎
- **描述**：提供“新品介绍”“活动预热”“口播讲解”“图文转视频”等模板，用户选择后可一键载入默认镜头结构、字幕版式和动效节奏。
- **输入**：模板类别、视频比例、行业标签
- **处理逻辑**：加载模板元数据（镜头数、默认时长、字幕样式、适用素材位）并与创作上下文合并
- **输出**：可编辑的模板化分镜结构
- **异常场景**：当前模板不适配用户素材数量时，提示补传素材或切换模板

#### 4.2.3 自动生成分镜草稿

- **所属模块**：成片生成
- **描述**：根据脚本和模板生成 3-6 段镜头草稿，每段包含镜头标题、字幕草稿、素材建议、预计时长。
- **输入**：创作上下文、模板规则、用户素材
- **处理逻辑**：按模板规则拆分内容段落，生成镜头顺序、字幕文案和素材位分配
- **输出**：分镜卡片列表、预览区占位图、建议总时长
- **异常场景**：脚本无法自动拆分时退回 3 段默认结构，并提示用户手动调整

#### 4.2.4 字幕自动生成与编辑

- **所属模块**：成片生成
- **描述**：每个分镜自动生成字幕，并支持逐条编辑、删减和重新生成。
- **输入**：分镜文案、字幕风格、品牌语气
- **处理逻辑**：按镜头节奏拆分字幕句段，并做字数限制与重点词高亮
- **输出**：字幕列表、预览区字幕占位
- **异常场景**：字幕过长、超出模板安全区时高亮提示并建议精简

#### 4.2.5 素材合规与敏感词校验

- **所属模块**：导出与风控
- **描述**：在导出前校验缺失素材、敏感词、过长字幕、音频未选择等问题。
- **输入**：项目配置、字幕文本、素材清单、导出参数
- **处理逻辑**：执行规则校验，按严重级别给出“阻止导出 / 警告可继续”两类反馈
- **输出**：校验结果列表、修复建议
- **异常场景**：高风险内容直接阻止导出；低风险内容允许用户确认后继续

#### 4.2.6 9:16 导出与平台预设

- **所属模块**：导出与风控
- **描述**：支持导出 9:16 MP4，并提供抖音、小红书、视频号等平台建议。
- **输入**：导出比例、清晰度、字幕开关、配音/BGM 方案
- **处理逻辑**：按导出模版合成视频资源，生成下载地址和平台建议文案
- **输出**：MP4 文件、导出记录、平台发布建议
- **异常场景**：渲染失败、超时、素材缺失时给出具体原因和重试入口

#### 4.2.7 素材上传与替换

- **所属模块**：素材管理
- **描述**：支持上传图片、Logo、封面图和补充素材，并替换到指定镜头。
- **输入**：本地文件、拖拽上传、素材位选择
- **处理逻辑**：校验格式与尺寸，生成缩略图，占位绑定到镜头卡片
- **输出**：素材库列表、镜头引用关系
- **异常场景**：格式不支持、尺寸过小或文件过大时提示用户重新上传

#### 4.2.8 项目保存与复用

- **所属模块**：项目管理
- **描述**：支持保存当前项目草稿、复制已有项目、查看最近导出历史。
- **输入**：项目标题、模板、镜头配置、素材引用
- **处理逻辑**：存储项目快照与导出状态，支持按模板/时间筛选与复制
- **输出**：项目列表、最近编辑时间、项目状态
- **异常场景**：未登录用户提示仅本地保存；登录用户可同步云端

#### 4.2.9 AI 配音与 BGM 推荐

- **所属模块**：增值能力
- **描述**：根据模板和脚本推荐配音风格与背景音乐类型，减少人工选择成本。
- **输入**：视频类型、行业、时长、语气偏好
- **处理逻辑**：返回 1-3 组推荐项，并允许试听或切换
- **输出**：配音方案、BGM 风格建议、试听入口
- **异常场景**：推荐失败时回退到默认方案并允许用户手动跳过

#### 4.2.10 封面标题与发布文案建议

- **所属模块**：增值能力
- **描述**：导出前自动生成封面标题、简介和平台发布文案建议。
- **输入**：视频主题、卖点摘要、模板类型
- **处理逻辑**：生成 2-3 组不同风格的标题/文案供复制
- **输出**：封面标题、简介、标签建议
- **异常场景**：若生成内容重复或质量偏低，支持再次生成

## 5. 非功能需求

| 类别 | 需求描述 | 指标 |
|------|----------|------|
| **性能** | 创作向导与模板加载速度 | 页面首屏加载 ≤ 2s，模板切换 ≤ 300ms |
| **性能** | 分镜草稿生成速度 | 首次生成分镜 ≤ 15s |
| **性能** | 导出体验 | 30 秒以内视频导出 ≤ 60s（P95） |
| **可用性** | 系统可用率 | SLA ≥ 99.5% |

## 7. 技术方案概要

### 7.1 技术选型

| 层级 | 技术选型 | 说明 |
|------|----------|------|
| 前端 | Next.js 14 + React + TypeScript | 复用现有 Web 端技术基础，适合构建创作工作台和项目页 |
| UI | Tailwind CSS + shadcn/ui | 提升中后台式编辑体验与交互一致性 |
| 后端 | Next.js API Routes / Serverless | 承载项目管理、模板、导出任务发起等 API |
| 渲染/转码 | FFmpeg 渲染服务（异步任务） | 用于模板化镜头拼接、字幕叠加和 MP4 导出 |
| 存储 | Supabase + 对象存储 | 保存项目数据、模板配置与用户素材 |
| AI 能力 | OpenAI / 语音服务 / 字幕生成能力 | 用于文案优化、字幕改写、封面标题建议、AI 配音 |
| 部署 | Vercel + 异步任务执行环境 | Web 与 API 走 Vercel，导出任务采用独立异步执行 |

### 7.2 系统架构概述

```
用户浏览器（创作工作台）
    ├── 脚本/素材输入
    ├── 模板中心
    ├── 分镜预览与字幕编辑
    ├── 导出中心
    └── 项目库

Next.js API / BFF
    ├── /api/projects        → 项目保存、复制、查询
    ├── /api/templates       → 模板列表、模板详情
    ├── /api/storyboard      → 分镜草稿生成
    ├── /api/export          → 发起导出任务、查询状态
    ├── /api/voice           → 配音/BGM 推荐
    └── /api/compliance      → 敏感词/素材校验

异步渲染层
    ├── 拉取项目配置
    ├── 合成模板镜头、字幕、音轨
    ├── 输出 MP4 与封面
    └── 回写导出状态

数据与资源层
    ├── projects / templates / exports 表
    ├── 用户素材对象存储
    └── 导出产物与日志
```

**渲染链路补充说明：**

1. **异步任务机制**：导出请求不在 Web 请求中同步完成，而是创建导出任务并写入任务队列，前端通过轮询或状态刷新查看进度。
2. **渲染步骤**：读取项目配置 → 拉取模板和素材 → 合成镜头序列 → 叠加字幕/封面/音轨 → 输出 MP4 与封面图 → 回写状态与下载地址。
3. **存储策略**：项目配置、模板元数据和导出记录存结构化存储；用户上传素材与成片文件走对象存储，并使用临时签名链接下载。
4. **失败兜底**：渲染失败需保留错误码、失败步骤和可重试标记，导出中心可直接展示“返回修复 / 重新导出”入口。

> 本章节仅提供 PRD 级概要。由于本次为 Major 方向调整，现有 `architecture-videoprompt-ai.md` 需同步改版，重点补齐渲染任务、存储、合规与导出链路设计；**架构评审通过前，不进入开发排期执行。**

## 附录 A：需求分析报告

### A.1 V1.0 需求分析（双模型提示词阶段）

> 完整报告见 [analysis-report.md](analysis-report.md)

- **产品定位**：AI 视频提示词智能编辑器（Web App），适配 Sora 2 + Seedance 2.0。
- **核心功能**：结构化参数面板、AI 智能扩写、双模型格式输出、场景模板库、提示词管理。
- **市场判断**：缺乏同时适配 Sora + Seedance 的视频提示词工具，定位清晰，建议快速验证。
- **价值结论**：适合在 AI 视频创作早期阶段，以“降低提示词创作门槛”为主诉求切入。

### A.2 V2.0 需求分析（通用模型扩展阶段）

> 完整报告见 [analysis-report-universal-model.md](analysis-report-universal-model.md)

- **产品定位**：从双模型视频提示词工具扩展为“通用 AI 模型提示词生成平台”。
- **新增方向**：覆盖更多视频模型（Runway/Kling/Veo/Pika）和图像模型（MJ/SD/DALL-E/Firefly）。
- **关键发现**：市场存在“宽且深”的多模型提示词适配机会，但 UI 与维护复杂度快速上升。
- **价值结论**：高价值，但建议缩范围推进，分阶段扩展模型覆盖。

### A.3 V3.0 需求分析（短视频合成方向）

> 完整报告见 [analysis-report-short-video-synthesis.md](analysis-report-short-video-synthesis.md)

#### A.3.1 需求概述

- **灵感描述**：做一个短视频合成的 app。
- **分析模式**：基于 `prd-videoprompt-ai.md` v2.0 的迭代分析。
- **核心功能点**：脚本/图文输入、模板化镜头编排、字幕/配音/BGM、一键导出、项目保存复用。
- **核心痛点**：短视频制作链路碎片化；非专业用户不会做镜头编排；纯 AI 文生视频不可控且成本高。

#### A.3.2 内部查重结果

- **飞书查询状态**：未完成。
- **原因**：当前环境缺少 `FEISHU_APP_ID`、`FEISHU_APP_SECRET`、`~/.feishu_mcp_token` 与 `FEISHU_MCP_UAT`，无法完成 OAuth 与内部知识库检索。
- **阶段判断**：结合本地文档，属于与现有 VideoPrompt AI 高相关、但产品边界明显扩大的增量方向。

#### A.3.3 竞品分析摘要

| 产品 | 定位 | 启示 |
|------|------|------|
| Runway / Pika / Kling | AI 原生生成型视频工具 | 生成能力强，但对营销/商家场景的稳定成片流程支持有限 |
| Canva / CapCut / InVideo / VEED | 模板化内容生产工具 | 证明“快速成片”需求成立，但通用编辑器竞争强 |

- **市场空白**：不是“没人做短视频”，而是缺少对非专业用户更友好的“脚本/图文 → 可发布短视频”闭环。
- **差异化机会**：把既有创意输入能力升级为模板化成片工作流，聚焦营销/电商/图文转视频场景。

#### A.3.4 价值评估

| 维度 | 评分 | 说明 |
|------|------|------|
| 创新度 | 3/5 | 赛道已有工具，但“创意输入 + 模板成片”闭环仍可形成差异化 |
| 市场需求度 | 4/5 | 创作者、商家和营销团队对低门槛视频生产有持续需求 |
| 实现难度 | 5/5 | 相比提示词工具，导出、转码、素材、合规链路复杂度大幅上升 |
| 竞争优势 | 3/5 | 若不聚焦场景会直面巨头；聚焦模板化营销视频则有机会 |
| 商业可行性 | 3/5 | 商业模式清晰，但需要控制渲染与素材成本 |
| 综合评分 | 3.2/5 | 建议缩范围推进 |

#### A.3.5 结论与建议

- **结论**：⚠️ 建议缩范围推进。
- **核心建议**：先做“脚本/图文 → 模板化短视频 → 一键导出”的 MVP，不做全功能编辑器，也不在首版重压纯 AI 文生视频。
- **版本判断**：属于 Major 变更，需同步更新架构文档与后续设计资产。

> **计算公式**：RICE 分 = (Reach × Impact × Confidence) / Effort
>
> - **Reach（影响面）**：一个迭代周期内，该功能直接影响的用户数量（1-10 等级）
> - **Impact（影响度）**：对单个用户的价值影响程度（3=巨大 / 2=高 / 1=中 / 0.5=低 / 0.25=极低）
> - **Confidence（信心度）**：对上述 R、I 估算的信心程度（100%=高 / 80%=中 / 50%=低）
> - **Effort（工作量）**：实现该功能需要的人月数（数值越大表示工作量越高）
> - **闭环例外规则**：若某功能虽然 RICE 分不占优，但它决定核心流程是否闭环、属于合规/风控阻断项，或是用户获得首个成功结果的必要出口，可保留为 P0，并需在 §4.1 或评审结论中明确说明原因。
